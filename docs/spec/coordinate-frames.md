# 坐标系约定

本项目所有坐标系的唯一定义。代码注释、配置、其它文档里说到“起飞坐标系 / 机体坐标系 / 世界坐标”，
都指这里的定义。决策依据见 [ADR-0011](adr/0011-pilot-arm-takeoff-point-frame.md)。

**一句话**：接口层以上（测试、任务、感知、决策、配置）只有两种坐标——**起飞坐标系**和**机体坐标系**，
都是“前-右-下”。东南西北、经纬度、海拔只存在于飞控内部和接口层内部。

## 1. 地理坐标系（WGS-84）

经度 / 纬度 / 海拔（MSL）。只在飞控（GPS、EKF）和接口层内部使用。对外只有两处保留原样：
`~/telemetry/global_position`（`NavSatFix`）和 `~/goto_location` 服务——任务不使用它们。

飞控自己的局部坐标（`LOCAL_POSITION_NED`：EKF 原点、北/东/地）也属于这一类“飞控内部坐标”，
**只在 `interface_node` 里出现**，换算后才对外。

## 2. 起飞坐标系（任务里说的“绝对坐标”）

| 项 | 定义 |
|---|---|
| 原点 | 飞手解锁那一刻**飞控**的位置（不是地面：地面在原点下方 `fc_rest_clearance_m` = 0.31m） |
| x 轴 | 解锁那一刻的**机头方向**（前） |
| y 轴 | 解锁那一刻机头的**右侧** |
| z 轴 | 向下（高度 = −z，即飞控相对起飞时自身位置的高度；起落架底此时恰好离地 −z） |
| 航向 | 0 = 起飞时机头方向，向右转为正 |
| 何时确定 | 每次解锁时冻结；上锁后保持（落地后读数仍相对起飞点），下次解锁重新确定；从未解锁过时跟随飞机当前位置和朝向（读数 ≈ 0） |

它只取决于**飞机起飞前怎么摆**，和东南西北、经纬度、海拔都无关。摆放朝向偏 1°，32.5m 外的投放区
横向偏约 0.57m——比赛时飞机放在起降点、机头对准投放区方向。

用到它的：`~/telemetry/local_position`、`~/telemetry/velocity`、`~/telemetry/attitude` 的航向、
`~/cmd/position_target_local`、`~/cmd/yaw`，感知输出的目标位置（`Detection.position`、`vehicle_pose`），
任务配置里的场地坐标，飞行测试的方框。

**任务配置里的场地坐标**轴向与起飞坐标系相同（+x 前、+y 右），原点可以放在场地任意位置，
`takeoff_point` 给出起降点在场地坐标里的位置，换算只做平移。规则书
（[field-layout.md](field-layout.md)）的 y 轴取**左**侧，填配置时左侧距离取负号。

## 3. 机体坐标系（“局部相对坐标”）

原点 = 飞控当前位置；x = 当前机头方向，y = 当前右侧，z = 向下；随飞机移动和转动。

用到它的：`~/cmd/velocity`（机体系速度）、`~/cmd/position_target`（机体相对偏移）、
机体固定几何（相机、投放口、起落架相对飞控的位置，见 `cuadc_physical/airframe.yaml`）、
末端瞄准的“目标相对相机正下方”偏移和投放口杠杆臂。

起飞那一刻机体坐标系与起飞坐标系重合；之后两者相差飞机的位移和航向变化（飞行中锁航向时只差位移）。

## 4. 感知内部坐标（不对外）

- 相机坐标系：原点 = 相机光心，x = 图像右，y = 图像下，z = 镜头朝外。像素 → 射线在这里算。
- 相机相对机体的安装（位置 + 角度）在 `cuadc_physical/airframe.yaml`；感知把射线转到起飞坐标系，
  与筒顶平面（`down = fc_rest_clearance_m − 筒高`）求交后对外发布。

## 5. 仿真对应关系

Gazebo 世界坐标（`cuadc_sim/field/config.py`：x = 前进方向，y = 左）。仿真飞机出生在起降点、
机头朝世界 +x，所以 起飞坐标系 前 = 世界 x − 出生点 x，右 = −(世界 y − 出生点 y)。SITL 的 EKF 原点是
世界原点、航向估计与真朝向有 1–2° 偏差——这些都被接口层吸收，和真机同一套换算。仿真专用工具
（桩感知、反投影量测）拿世界真值比对时按上式换算。
