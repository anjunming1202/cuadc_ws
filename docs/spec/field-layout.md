> 适用项目：2026 中国大学生飞行器设计创新大赛——多旋翼无人机侦察与救援  
> 用途：仿真建图、任务状态机设计、路径规划、视觉算法测试、数字孪生和现场复测  
> **本文件性质**：我们自己的建模设计（坐标系选择、参数化方式、双场地推荐

## 1. 定义范围与解释原则

本文件定义一块标准比赛场地的二维平面布局，并进一步给出两块并行比赛场地的推荐建模方式。

场地由以下区域组成：

1. 准备区；
2. 起降区；
3. 起降点；
4. 起飞线；
5. 投放区；
6. 投放区与侦察区之间的过渡区；
7. 灾情侦察区；
8. 两块并行场地之间的隔离间距；
9. 场地外安全区。

规则明确给出的尺寸均视为**标称尺寸**。规则同时说明，任务区各规定尺寸可能存在误差，最终以现场实际测量为准。因此，本文件适合定义“标准模型”，正式比赛前仍须进行现场复测并更新坐标。

本文件不会把示意图中的透视、倾斜或前后错位解释为真实几何角度。实际建模时，各主要区域均按矩形、平行线和垂线处理。

---

## 2. 坐标系定义

对每一块比赛场地建立独立右手二维坐标系：

- 原点 `O = (0, 0)`：起降点圆心；
- `+x` 方向：由准备区指向投放区、侦察区；
- `+y` 方向：面向侦察区时的左侧；
- 场地纵向中心线：`y = 0`；
- 所有长度单位均为米，除非另有说明。

在该坐标系下：

- 纵向表示任务推进方向；
- 横向表示场地宽度方向；
- 所有主要矩形区域的边均与 `x` 轴或 `y` 轴平行。

---

## 3. 一块标准场地的总体尺寸链

一块场地沿 `x` 方向的关键位置依次为：

```text
准备区
  │
  │ x = -3：准备区与起降区分界线
  │
  ├── 3 m ──► x = 0：起降点圆心
  │
  ├── 2 m ──► x = 2：起飞线
  │
  ├──────── 30 m ────────► x = 30：投放区近端边界
  │
  ├── 投放区纵向长度 5 m ─► x = 35：投放区远端边界
  │
  ├──── 过渡区 20 m ─────► x = 55：侦察区近端边界
  │
  └── 侦察区纵向长度 5 m ─► x = 60：侦察区远端边界
```

因此：

- 起降区后边界至起降点圆心：`3 m`；
- 起降点圆心至投放区近端：`30 m`；
- 投放区纵向长度：`5 m`；
- 投放区远端至侦察区近端：`20 m`；
- 起降点圆心至侦察区近端：`55 m`；
- 起降点圆心至侦察区远端：`60 m`；
- 起降区后边界至侦察区远端：`63 m`。

其中：

```text
30 + 5 + 20 = 55
3 + 30 = 33
3 + 30 + 5 + 20 + 5 = 63
```

这些等式构成场地纵向几何的一致性检查。

## 4. 起降区

### 4.1 尺寸

起降区为矩形：

- 长度：`33 m`；
- 宽度：`8 m`。

在本坐标系中，起降区定义为：

```math
R_{takeoff} = \{(x,y)\mid -3 \le x \le 30,\ -4 \le y \le 4\}
```

因此：

- 后边界：`x = -3`；
- 前边界：`x = 30`；
- 左边界：`y = 4`；
- 右边界：`y = -4`；
- 中心线：`y = 0`。

起降区面积为：

```text
33 × 8 = 264 m²
```

### 4.2 几何关系

- 起降区长边平行于 `x` 轴；
- 起降区短边平行于 `y` 轴；
- 起飞线位于起降区内部；
- 起降点位于起降区内部；
- 起降区前边界与投放区近端边界重合。

---

## 5. 准备区

准备区位于起降区后边界外侧，即 `x < -3` 一侧。

规则只明确：

- 准备区位于起降区靠近起降点一端的边线外侧；
- 起降点圆心距离准备区边界 `3 m`。

因此，准备区与起降区的分界线定义为：

```math
x = -3
```

准备区的纵向深度未被规则固定，不能从示意图推导为确定数值。建模时应将其参数化：

```text
准备区深度 = L_prep
```

其中：

```text
L_prep > 0
```

若仅用于任务仿真，可采用一个工程默认值，例如：

```text
L_prep = 5 m
```

但该默认值不是官方规定，正式部署前应以现场测量值替换。

若准备区与起降区等宽，则其标准化模型可写为：

```math
R_{prep} = \{(x,y)\mid -3-L_{prep} \le x < -3,\ -4 \le y \le 4\}
```

---

## 6. 起降点

### 6.1 尺寸与位置

起降点为圆形区域：

- 圆心：`O = (0, 0)`；
- 直径：`0.8 m`；
- 半径：`0.4 m`；
- 圆内设置“H”标识。

其几何定义为：

```math
R_H = \{(x,y)\mid x^2+y^2 \le 0.4^2\}
```

### 6.2 与周围边界的距离

- 圆心到起降区后边界：`3 m`；
- 圆心到起飞线：`2 m`；
- 圆心到投放区近端：`30 m`；
- 圆心到侦察区近端：`55 m`。

起降圆后缘到起降区后边界的净距为：

```text
3 - 0.4 = 2.6 m
```

起降圆前缘到起飞线的净距为：

```text
2 - 0.4 = 1.6 m
```

### 6.3 着陆判定几何

着陆成功的几何判定基于飞行器所有对角线方向旋翼轴连线交叉点在地面上的投影。该投影必须位于起降点圆内，压线视为入内。

如果该投影坐标为 `(x_uav, y_uav)`，则几何判定条件为：

```math
x_{uav}^2 + y_{uav}^2 \le 0.4^2
```

---

## 7. 起飞线

起飞线位于起降点前方 `2 m`，定义为：

```math
L_{start} = \{(x,y)\mid x=2,\ -4 \le y \le 4\}
```

几何性质：

- 与场地中心线垂直；
- 与起降区前后边界平行；
- 横贯起降区宽度；
- 位于起降区内部；
- 与投放区近端边界相距：

```text
30 - 2 = 28 m
```

比赛判定中，无人机携带两个标准载荷飞越起飞线，才视为起飞成功。

---

## 8. 投放区

### 8.1 外部矩形

投放区尺寸为：

- 横向宽度：`8 m`；
- 纵向长度：`5 m`。

其标准几何定义为：

```math
R_{drop} = \{(x,y)\mid 30 \le x \le 35,\ -4 \le y \le 4\}
```

对应边界：

- 近端边界：`x = 30`；
- 远端边界：`x = 35`；
- 左边界：`y = 4`；
- 右边界：`y = -4`。

投放区面积：

```text
8 × 5 = 40 m²
```

投放区几何中心：

```text
C_drop = (32.5, 0)
```

### 8.2 与其他区域的关系

- 投放区近端边界与起降区前边界重合；
- 投放区与起降区横向完全对齐；
- 投放区与侦察区共用同一纵向中心线 `y = 0`；
- 投放区远端与侦察区近端之间保留 `20 m` 过渡区。

### 8.3 投放筒

投放区内随机放置 3 个白色圆筒：

| 编号 | 直径 | 半径 | 高度 |
|---|---:|---:|---:|
| 1 号筒 | 0.15 m | 0.075 m | 0.30 m |
| 2 号筒 | 0.20 m | 0.10 m | 0.30 m |
| 3 号筒 | 0.25 m | 0.125 m | 0.30 m |

定义第 `i` 个筒的圆心为：

```text
D_i = (x_i, y_i),  i ∈ {1,2,3}
```

其位置必须位于投放区内。若要求圆筒完整落在投放区内部，则需满足：

```math
30+r_i \le x_i \le 35-r_i
```

```math
-4+r_i \le y_i \le 4-r_i
```

其中 `r_i` 为对应圆筒半径。

规则未给出：

- 圆筒之间的最小间距；
- 圆筒距边界的额外安全距离；
- 圆筒固定排列；
- 圆筒每轮是否重新布置。

因此，算法不得依赖固定坐标，应通过视觉或现场公布信息获取实际位置。

## 9. 投放区有效判定几何

每个投放筒周围包含两类有效区域：

### 9.1 A 区

A 区为圆筒内部区域。

若第 `i` 个筒的内侧有效半径近似按筒半径 `r_i` 处理，则：

```math
A_i = \{(x,y)\mid (x-x_i)^2+(y-y_i)^2 \le r_i^2\}
```

标准载荷第一落点位于圆筒内侧壁或筒底，视为投中 A 区。

### 9.2 B 区

B 区为以筒心为圆心、直径 `1 m` 的筒外圆环区域。

外半径：

```text
R_B = 0.5 m
```

因此可建模为：

```math
B_i = \{(x,y)\mid r_i^2 < (x-x_i)^2+(y-y_i)^2 \le 0.5^2\}
```

压线视为入内。

### 9.3 无效区

投放区中除全部 A 区和 B 区以外的部分为无效区：

```math
R_{invalid,drop} = R_{drop} \setminus \bigcup_{i=1}^{3}(A_i\cup B_i)
```

标准载荷投放区的判定以第一落点为准。

---

## 10. 投放区与侦察区之间的过渡区

过渡区为投放区远端与侦察区近端之间的矩形走廊：

```math
R_{transition} = \{(x,y)\mid 35 < x < 55,\ -4 \le y \le 4\}
```

尺寸：

- 纵向长度：`20 m`；
- 横向宽度：`8 m`；
- 面积：

```text
20 × 8 = 160 m²
```

该 `20 m` 是两个区域边界之间的净距，不是两个区域中心之间的距离。

投放区中心到侦察区中心的距离为：

```text
2.5 + 20 + 2.5 = 25 m
```

## 11. 灾情侦察区

### 11.1 外部矩形

侦察区尺寸为：

- 横向宽度：`8 m`；
- 纵向长度：`5 m`。

其几何定义为：

```math
R_{recon} = \{(x,y)\mid 55 \le x \le 60,\ -4 \le y \le 4\}
```

边界：

- 近端边界：`x = 55`；
- 远端边界：`x = 60`；
- 左边界：`y = 4`；
- 右边界：`y = -4`。

侦察区面积：

```text
8 × 5 = 40 m²
```

侦察区几何中心：

```text
C_recon = (57.5, 0)
```

### 11.2 侦察筒

侦察区内随机放置 5 个白色圆筒：

- 数量：`5`；
- 直径：`0.20 m`；
- 半径：`0.10 m`；
- 高度：`0.15 m`。

定义第 `j` 个侦察筒圆心为：

```text
Q_j = (u_j, v_j),  j ∈ {1,2,3,4,5}
```

若要求圆筒完整落在侦察区内部，则：

```math
55+0.10 \le u_j \le 60-0.10
```

```math
-4+0.10 \le v_j \le 4-0.10
```

规则未给出筒与筒之间的固定间距或固定排列。

### 11.3 危险化学品标识

5 个侦察筒中，随机选择 3 个，在筒内各放置一个危险化学品标识。

标识尺寸：

```text
0.12 m × 0.12 m
```

标识的类型、所在筒以及筒的位置均具有随机性。

因此视觉系统必须处理：

1. 五个筒坐标随机；
2. 只有三个筒包含标识；
3. 标识类别随机；
4. 识别结果需关联到具体筒的位置。

## 13. 双场地布局

比赛采用两组同时比赛，两块场地布局相同、位置相邻，场地之间间隔不小于 `5 m`。

### 13.1 最小间隔定义

若两块场地均宽 `8 m`，且平行并排，则最近边界净距必须满足：

```math
d_{edge} \ge 5
```

两块场地中心线之间的距离应满足：

```text
4 + 5 + 4 = 13 m
```

即：

```math
d_{centerline} \ge 13
```

### 13.2 推荐标准化坐标

场地 A：

```text
中心线：y = 0
横向范围：-4 ≤ y ≤ 4
```

场地 B 可放置在场地 A 左侧，并采用最小允许间隔：

```text
中心线：y = 13
横向范围：9 ≤ y ≤ 17
```

此时两块场地之间的净距为：

```text
9 - 4 = 5 m
```

也可将场地 B 放置在另一侧：

```text
中心线：y = -13
横向范围：-17 ≤ y ≤ -9
```

### 13.3 双场地参数化表达

设场地编号 `k ∈ {A,B}`，其中心线横坐标偏移为 `y_k`，则所有区域可由单场地模型作平移得到：

```math
(x,y) \mapsto (x, y+y_k)
```

若采用最小间隔标准模型：

```text
y_A = 0
y_B = 13
```

两块场地不应在仿真中共享投放筒、侦察筒或随机目标实例。

## 14. 安全区

规则说明：

- 安全区根据现场条件划定；
- 观众区、准备区等位于安全区内。

安全区外轮廓未由示意图或规则给出固定尺寸，因此不能在标准模型中写死。

建议将安全区建模为参数化多边形：

```text
SafetyZone = Polygon(P_1, P_2, ..., P_n)
```

并要求：

- 准备区位于安全区内；
- 观众区位于安全区内；
- 任务区边界、人员区和飞行禁入边界由现场测绘确定；
- 正式比赛前，将安全区多边形写入地理围栏或仿真地图。

## 15. 三维模型中仍需补充的参数

本文件完整定义了规则中可确定的二维平面布局，但规则未固定以下三维参数：

- 起飞高度；
- 巡航高度；
- 投放高度；
- 侦察高度；
- 相机俯仰角；
- 飞行器与筒之间的最小安全高度；
- 筒体壁厚；
- 场地地面高程变化；
- 风场和障碍物信息。

这些内容应作为独立任务参数定义，而不应从二维示意图中推断。

## 17. 不能由规则完全确定的项目

以下内容必须保留为变量或通过现场测量获得：

1. 准备区纵向深度；
2. 安全区外轮廓；
3. 观众区、审核区和裁判区的具体位置；
4. 两块场地是否存在纵向错位；
5. 两块场地实际间距，规则只规定不小于 `5 m`；
6. 投放筒具体坐标；
7. 侦察筒具体坐标；
8. 三个危险品标识所在筒及类别；
9. 现场尺寸误差；
10. 飞行高度、航线高度与相机姿态。

若软件系统要求“完全闭合”的几何模型，应将这些项目明确建模为配置参数，而不是隐含假设。

## 18. 现场复测清单

正式比赛或实地训练前，应至少复测：

- 起降区实际长度和宽度；
- 起降点圆心坐标和实际直径；
- 起飞线位置；
- 投放区四角坐标；
- 侦察区四角坐标；
- 两块场地最近边界间距；
- 两块场地中心线是否平行；
- 投放筒中心坐标和直径；
- 侦察筒中心坐标和直径；
- 安全区边界；
- 场地坐标系相对于地理北向的航向角；
- 地面坡度、障碍物和视线遮挡。

复测后，应通过刚体变换将标准局部坐标系映射到现场坐标系：

```math
p_{world} = R(\psi)p_{local} + t
```

其中：

- `p_local`：本文件定义的局部场地坐标；
- `R(ψ)`：场地相对于世界坐标系的二维旋转矩阵；
- `t`：场地原点在世界坐标系中的平移向量；
- `ψ`：场地 `+x` 轴的实际航向角。

关键边界坐标和随机化参数的汇总，见 §12 表格和 §16 的 YAML，不在此重复。
