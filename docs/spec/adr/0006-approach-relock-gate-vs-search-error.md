# 0006. 接近段硬锁关联门要匹配 SEARCH 定位误差（否则末端交接卡死）

**Status**: Accepted

## Context

[ADR-0005](0005-terminal-align-visual-servoing.md) 定的混合接近里,粗段 PBVS
把飞机带到 SEARCH 估计出的**世界锁定坐标**上方,然后交接给末端 IBVS。交接的
前提在 `approaches/stepped_descent_ibvs.py` 的 `_coarse`:必须先用
`_nearest_within(dets, lock, refine_gate_m)` 拿到一个**离锁定点 `refine_gate_m`
以内的实时检测**(硬锁关联,`best`),`best` 非空才可能切末端(末端 IBVS 也靠
这个检测的 bearing 才有测量)。

问题:SEARCH 对每个筒的位置估计**带的正是 ADR-0005 说的 0.5–2.5m 世界定位
误差**(反投影几何 + 局部漂移 + 近 nadir 退化;远筒欠采样时更偏)。而
`refine_gate_m` 原值 **0.4m < 典型定位误差(~0.5m)**。于是真实筒的检测常常
落在关联门**外** → `best=None` → 交接永不触发 → 飞机停在偏掉的锁定点上悬停 →
投放区任务超时守卫(`_check_guards`)到时**放弃投放**。

用 SEARCH 压力测试台([`sim-stress-testbed.md`](../sim-stress-testbed.md))可复现:
第二次投放常因此失败,基线成功率 2/5(~40%,双峰:快轮投满 / 慢轮悬停 106s 放弃)。
这条失败链、以及三路并行方案的横向验证,记在探索纪要
[`search-hardening-charter.md`](../search-hardening-charter.md)。

## Decision

**关联门必须 ≥ 该环境下 SEARCH 的期望定位误差,同时 < 半个最小可能筒间距。**
它是按 profile 分档的 yaml 旋钮,sim/real 各自取值。

- **sim 档**:`refine_gate_m` 0.4 → **0.65**(筒距 1.5m,0.65 < 0.75 安全)。真实筒
  检测被接受 → 交接触发 → 末端 IBVS(对定位偏置免疫)收敛到真实筒。
- **real 档**:留待现场实测定(竞赛规则不保证最小筒间距,门取值要权衡实测
  定位误差 vs 实际摆放;根本缓解是减小定位误差,见 Consequences)。
- 附带修一个真 bug:投放成功后 `drop_task.waypoint_index = 0` 复位,否则二次
  搜索停在末航点、原地不动、只吃上一轮欠采样的旧簇。

## Consequences

- 压测台:第二次投放成功率 **2/5 → 5/5**,每轮 ~40s(106s 悬停-放弃模式消失)。
  GUI 抽验通过。提交 `9b849e0`。
- **代价 / 真机风险**:门放宽 = 硬锁对"相邻筒"的判别裕度变小。真机若两筒靠得
  很近(规则不保证间距),宽门可能关联到相邻筒的检测。缓解:(a) real 门单独按
  实测调;(b) 减小 SEARCH 定位误差(让门能留窄)——中位数聚合 / 增采样等手段
  探索过(见下),留作后续鲁棒性杠杆。
- 加扰动(风/传感器噪声/感知时延,压测台下一步)会**放大**定位误差,届时门与
  估计精度的权衡要重估——这也是保留估计鲁棒性手段的原因。

## Alternatives considered（并行方案横向比,n=5）

- **放宽末端交接的米制门 `handoff_off_m`(方案 B)**:无效(20%)。绑定约束是
  `best=None`(硬锁门),不是米制门;不碰 `refine_gate_m` 就改不了失败。
- **中位数聚合替代簇均值(方案 A)**:干净 sim 中性(20%,噪声内)——干净 sim 的
  偏差是系统性/簇碎裂,中位数消不掉。对**偶发坏帧**有效,故留作加扰动后的鲁棒性
  手段,本次不纳入。
- **驻留增采样 + per-drop 守卫预算(方案 C 全量)**:60%,但引入 0-drop 回归;门
  修复后其增采样/守卫改动变得不必要,只保留其发现的重搜 `waypoint_index` 真 bug。
- **只减小 SEARCH 误差、保持窄门**:未证明单独够用(A/C 均未达标);作为真机
  相邻筒安全的方向保留,与本决策互补而非替代。
