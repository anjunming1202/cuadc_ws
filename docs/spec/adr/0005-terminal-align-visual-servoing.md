# 0005. 投放末端对准用图像伺服（IBVS），粗接近保持位置控制（hybrid）

**Status**: Accepted

## Context

[`06-planning.md`](../06-planning.md) 的 `APPROACH_DROP_TARGET` 初版是闭环
**位置控制（PBVS）**：不断用最新一帧检测反投影出目标的世界坐标，往那个坐标
飞。它的终点精度受**世界坐标定位误差**限制，而这个误差不小：

- 误差来源不是检测——像素中心检测本身很准、置信度很高（`cv_explore/color_shape`
  实测检出率 94%，筒心稳定）。误差出在**从像素到世界这一步**：反投影几何
  （高度/内参/挂载标定）+ 接口层 `local_position`/GPS 的局部漂移 + 近 nadir
  的退化几何（射线接近竖直时地面交点对高度误差极敏感）。
- `cv_explore` 用「飞行器位姿 + 检测相对位置」做无真值聚类验证，实测这个
  端到端定位误差量级在 **0.5–2.5m**。

投放要求水平对准在 **±5–15cm 量级**（待筒径 + 投放高度最终 spec 定死）。
纯 PBVS 到不了这个精度——它被定位偏置卡住。

关键洞察：**直接用像素误差驱动速度（IBVS）对定位误差免疫**。把检测到的筒顶
中心压到画面里的期望点（载荷落点投影），飞机自然就在筒正上方；深度/标定/GPS
误差只改变收敛的快慢，不改变终点。代价是 IBVS 需要**目标在视野里**才有测量，
而巡航高度的 FOV 足迹很小（~±0.75m@2m），目标通常一开始并不在视野内。

## Decision

投放接近分两段（**hybrid**），不是二选一：

1. **粗接近（coarse，PBVS）**：巡航高度用世界坐标把飞机带到目标附近，即便
   目标一开始不在视野。这段只需要把飞机带到「目标能进视野」这个宽松目标，
   0.5–2.5m 的定位误差在这里完全够用。
2. **末端对准（terminal，IBVS）**：目标进视野且够近后切换，用**像素误差**
   驱动水平速度、把筒顶中心压到画面期望点，同时降高；居中 + 停稳（判据用
   **对地速度**，见下）+ 连续 N 帧稳定，才触发投放。

因此感知的对外契约要**额外暴露像素观测 `(u,v)`**，不能只发世界坐标——契约
扩展见 [`05-perception-decision-interface.md`](../05-perception-decision-interface.md)。
感知仍然**无状态、逐帧**，仍在内部做反投影发世界坐标（粗接近用），只是同一
条检测里**多带一个像素中心**（末端 IBVS 用），不新增职责、不做时序跟踪。

### 离线验证（`cv_explore/servo_align`，2026-09-20）

纯数学模型（点质量 + 针孔相机 + 控制律 + 注入延迟/噪声/丢帧/风/目标跳；
PBVS 按实测量级建模了随高度变化 + 残留偏置的定位误差）。对比三种末端形态、
两种起点，看真实落点误差与「目标一开始不在视野时能否收敛」：

| 起点 | pure IBVS | pure PBVS | hybrid |
|---|---|---|---|
| 目标在视野 | 2cm | 23cm | **4cm** |
| 视野外 / 远 | 投不出（看不到）| 22cm | **4cm** |

结论：hybrid 是**唯一**「既准（~4cm）又能从视野外收敛」的形态。纯 IBVS 准，
但必须一开始就在目标上方（通常做不到）；纯 PBVS 总能飞到，但被定位偏置卡在
~22cm，投放太粗。这是**证明「粗 PBVS→末端 IBVS」这个形态值得**的实验结论。

## Consequences

- **契约变更**：`Detection` 增加像素中心字段（见 05）。这是增量字段，只读
  世界坐标的老消费者不受影响；感知节点要把它填上。
- **06 的 `APPROACH_DROP_TARGET` 内部形态**从「纯 PBVS」细化为「粗 PBVS→末端
  IBVS」。06 里「视差随进近趋于垂直而自愈」的论证**仍然成立**：IBVS 把筒顶
  中心压向画面 nadir 点，飞机趋于正上方时筒顶中心与地面中心重合（筒轴竖直），
  是同一个自愈机制，只是改由像素误差驱动。属正常迭代/细化，不推翻 06。
- **定位误差（几何/GPS）不再是投放精度瓶颈**——它只决定粗接近能否把飞机带到
  「目标进视野」，末端精度由 IBVS 稳态 + 释放动力学决定。反过来，粗接近对
  定位精度的要求也因此放松了。
- **释放判据用对地速度**：顶风悬停时指令速度 = −风、但对地速度≈0，载荷出手
  后继承的是对地速度；离线 sim 证实按对地速度判「停稳」+ 加释放提前量，落点
  才准（否则顶风永远投不出去）。这是控制律实现细节，落在 approach 实现里。
- **实现落点不在本 ADR、也不在 spec**：stage-strategy 的组织、hybrid 的切换
  条件、姿态补偿 / alpha-beta 跟踪（门 + 重锁）/ 条件积分等控制细节，都属
  `cuadc_decision` 包内部组织，见 [`cuadc_decision/README.md`](../../../src/cuadc_decision/README.md)。
  第一份实现命名 `stepped_descent_ibvs`。
- **增益/门限是离线 sim 的起点，不是最终值**：上 Gazebo（真检测闭环）和真机
  时按真实延迟/动力学重调。
- **sim/real 同一份代码**（同 [`00-index.md`](../00-index.md) 的原则）：IBVS
  面对的是「像素观测 + 遥测」，这套输入不区分对面是 SITL 还是真机。
