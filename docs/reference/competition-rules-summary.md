## 1. 任务简述

固定翼无人机侦察与打击项目以军事作战需求为背景，模拟无人机战场侦察与打击的
应用场景，主要考察：
- 便携式固定翼无人机结构设计
- 自主飞行控制系统设计
- 目标物识别方法
- 精准定位打击方法
- 任务流程优化

任务要求：便携式固定翼飞行器携带模拟弹，通过**自主飞行**对未知区域的多个目标
进行侦察与识别，并对特定目标实施模拟打击。以侦察准确、打击精度高及任务用时
短取胜。

## 2. 飞行器技术要求

| 项目 | 要求 |
|---|---|
| 机型 | 仅限固定翼飞行器，机翼为硬质材料；升力面积、起飞重量、翼载荷不限 |
| 动力 | 仅限电机，数量 ≤ 2 个；功率/电压/容量不限；**禁止金属螺旋桨** |
| 任务箱 | 飞行器及所有相关设备（含比赛中读取信息用的手机/平板等）须完全置于长宽高之和 **≤ 1600mm** 的硬质长方体任务箱内，比赛期间不得破损 |
| 模拟弹 | 市售、符合国家标准的**未开封 350ml 瓶装水**（以标签标注为准），瓶身须清楚标记机组组长姓名 |
| 飘带 | 自备，≥1m 长、5cm 宽，红色；一端固定于模拟弹，其余不固定，确保投放时完全伸展、不缠绕打结 |
| 着陆方式 | 不限 |

### 自主飞行定义（关键约束）

> 自主飞行过程中，**不使用物理或虚拟摇杆对飞行器进行控制**，且**不对地面站
> 或上位机等地面设备进行任何操作**，直至飞行器着陆停稳。

可能带有物理/虚拟摇杆的设备包括但不限于：航模遥控器、游戏手柄、模拟飞行
摇杆、各类虚拟摇杆 App。

这条规则是感知/规划决策模块设计的硬约束：**侦察和打击阶段必须全程自主**，
一旦触碰摇杆或操作地面站/上位机，视具体阶段可能导致扣分、终止该轮比赛，甚至
取消资格（见第 7 节判罚）。

## 3. 场地设置

- 比赛区：起飞线、操纵区、起降区、目标区
- 安全区：审核区、待飞区、计时区、裁判区、观众区
- **起降区**：约 50×50m 跑道区域，A、B 两组共用
- **目标区**：约 60×60m，距起降区约 **200m**；分 A（蓝）、B（红）两个子区域，
  四角插旗划界
  - 每个子区域内有 **4 座天井**（间距 > 20m，高 400mm）
  - **3 座**天井内放置目标（另 1 座为空），靶标/天井箭头朝向随机
  - 以天井中心为圆心：**半径 4m = 精确打击区**，**半径 6m = 有效打击区**
  - 模拟弹仅允许投放在目标区内

## 4. 两种任务（各一轮）

| | 任务一（第一轮） | 任务二（第二轮） |
|---|---|---|
| 靶标 | 600×600mm 图片靶标，12 类，见 [target-classes.md](./target-classes.md) | 600×300mm 数字靶标 ×2/天井，组成两位数（0-99） |
| 侦察目标 | 识别 3 座天井各自的目标类别 | 识别 3 座天井各自的两位数 |
| 打击目标 | 目标**价值最高**的天井 | 数字为 3 个数中**中位数**的天井 |
| 打击依据 | 模拟弹第一落点 | 模拟弹第一落点 |

A 机组识别/打击蓝色天井，B 机组识别/打击红色天井。

## 5. 竞赛流程要点

- 每轮比赛时间 **8 分钟**，共 2 轮；须在时限内完成：装机、起飞、侦察、打击目标、
  返航着陆、填写记录单（返航着陆与填写记录单无顺序要求）
- 起飞、着陆均可自由选择自动或手动；但侦察与打击阶段必须自主飞行（见第 2 节）
- 若选自动起飞，须在起飞前将遥控器放地面；若选手动起飞，须在**进入目标区之前**
  放好遥控器，确认切换为自主飞行成功
- 若选自动着陆，须在**完全停稳后**才能拿起遥控器；若选手动着陆，须在**侦察打击
  任务完成后**才能拿起遥控器操纵返航
- 比赛时间内须填写侦察结果（天井对应的靶标名称/数字），结束后不可再改
- A、B 机组之间任何时候不得交流（含借用设备/工具）
- 指导教师不得进入场地或以任何形式指挥；机组不得随身携带通讯或电子设备

## 6. 成绩评定

单轮成绩 = 起飞分 + 侦察分 + 投弹（空投）分 + 着陆分 + 时间分。

| 分项 | 计分规则 |
|---|---|
| 起飞分 | 自动成功 300 / 手动成功 100 / 失败 0（携模拟弹飞离起降区即成功） |
| 侦察分 | 每座天井：填对 **+200**，填错 **−100**，不填 **0**；必须全程自主飞行才能得侦察分 |
| 投弹分 | 精确打击区 **500** / 有效打击区 **300** / 目标区内其它位置 **50** / 目标区外 **0** |
| 着陆分 | 自动成功 300 / 手动成功 100 / 失败 0（比赛时间内、飞行器无损、未携模拟弹，且从触地到停稳全程在起降区内） |
| 时间分 | `200 × (480 − T) / 480`，T = 比赛计时秒数；**只有完赛（起飞+侦察+有效空投+着陆停稳全部完成）才能得时间分**，否则为 0 |

> **有效空投**的定义：模拟弹正确投入规定区域内，**且** 3 个靶标名称/数字全部
> 填写正确，两者同时满足才算有效空投（这会影响时间分是否能拿到）。

总成绩 = 两轮单轮成绩之和；成绩相同则比两轮总用时，用时少者列前；仍相同则并列。

## 7. 判罚要点（详见规则原文第 19–24 页）

- **该轮成绩清零**（含多种情况）：起飞未携模拟弹、飞行中零件脱落/解体、两次
  飞越安全线、使用不符合自主飞行要求的方式控制飞行/投弹、自主飞行中操作
  地面站/上位机、比赛时间内任务箱破损、指导教师指挥或 A/B 组交流、随身携带
  通讯设备等
- **该轮终止但已得成绩有效**：进入目标区前未切换自主飞行、自主飞行中（投弹前）
  触碰遥控器、飞行中触地、模拟弹投至目标区外、记录单未填
- **仅着陆分清零**：着陆停稳但动力未关闭、未能落在起降区内、触地后零件脱落
- **取消比赛资格**：审核后未经允许打开任务箱、飞行中触碰任何人员、赛前赛后
  未关闭电源/未按指定位置放置任务箱
