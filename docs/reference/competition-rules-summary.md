## 1. 任务简述

多旋翼无人机侦察与救援项目以应急救援和危险品侦察任务为背景，聚焦侦察
救援无人机高精度、高效率、自动化的运行需求，主要考察：
- 多旋翼无人机自主飞行控制系统设计
- 目标识别方法
- 精准空投方法
- 快速部署能力

任务要求：多旋翼无人机携带规定的标准载荷，通过**全自动飞行**将标准载荷
投放至指定容器内，对侦察区的多个标识进行侦察与识别，返回起降区安全
着陆。以投放和侦察准确、任务用时短取胜。

## 2. 飞行器技术要求

| 项目 | 要求 |
|---|---|
| 机型 | 仅限电动机为动力的多旋翼飞行器；对角线方向旋翼轴间距 **≤550mm**；每个机组仅限使用一架飞行器 |
| 电池 | 最高输出电压 **≤26V(6S)**，数量不限，须为市售成品电池且表面标明参数 |
| 防护/安全 | 必须配备螺旋桨防护罩，并设置**可由人工切断动力的安全开关**（仅用于紧急停止） |
| 标准载荷 | 2 瓶市售带标签**未开封 550ml 饮用水**，自备；挂载方式自行设计；投放前视为飞行器一部分 |
| 干扰 | 两组同时比赛，机组间飞行器干扰自行解决，后果自负 |

### 自主飞行定义（关键约束）

> **飞行器启动后应以全自动方式完成比赛，比赛过程中不允许任何形式的
> 人工操纵**（原文 2.2 条）。

**没有"手动起飞/手动着陆"的选项**——从螺旋桨开始旋转（即飞行器"开启"）
那一刻起，直到比赛结束，全程不允许任何人工操纵，唯一允许的人工介入是
安全开关的紧急停止。这是感知/规划决策模块设计的硬约束：不存在"先人工
起飞再切自主"这种过渡阶段。

## 3. 场地设置

任务区由**起降区 → 投放区 → 灾情侦察区**三个子区域组成，顺序固定、
沿一条直线排列（见规则原文图1）：

- **起降区**：33m 长、8m 宽；起降点为直径 80cm 圆形区域，中间有"H"
  标识；起降点圆心距准备区 3m；起飞线在起降点前 2m 处。
- **投放区**（起降点前 30m 处）：8m 长、5m 宽；地面放置 3 个高 30cm
  的白色圆筒（1 号筒直径 15cm、2 号筒直径 20cm、3 号筒直径 25cm），
  随机放置。分有效区和无效区：有效区（地面蓝色）又分 A 区（筒内区域）
  和 B 区——B 区是"以筒心为圆心、**直径 1m 的圆**"去掉筒身后剩下的圆环
  区域（用规则原文图2 逐像素测量核对过：图上三个圆筒对应的**外圈直径
  完全相等**，只有内圈（筒身）大小随筒径 15/20/25cm 成比例变化，说明
  "1m"标的是外圈整体直径，不是环宽；筒越大，B 区环反而越窄）；无效区是
  投放区里 A、B 区以外的部分。**无需识别圆筒种类，只需精确空投命中**。
- **灾情侦察区**（投放区前方 20m，距起降点 55m）：8m 长、5m 宽；地面
  放置 5 个高 15cm、直径 20cm 的白色圆筒，位置随机，其中 **3 个**内
  各随机放置 1 个 12×12cm **危险化学品标识**（见
  [hazmat-placards.md](./hazmat-placards.md)，配合
  `附件1-13/附件11：危险化学品标识.pdf` 使用——**不是**附件12，附件12
  是固定翼项目的图片靶标，跟本项目无关）。
- 准备区：起降区靠近起降点一侧的边线外，供即将上场机组放置飞行器及
  设备。
- 安全区：观众区、准备区等根据场地条件划定。

## 4. 任务顺序（重要）

**先投放、后侦察**——飞行器必须先完成投放任务，才允许进入侦察区；未
完成投放即携带标准载荷进入侦察区会导致比赛终止（见第 7 节判罚）。

## 5. 竞赛流程要点

- 比赛共两轮，采用两组同时比赛的模式；两块场地布局相同、位置相邻，
  间隔不小于 5m。
- 赛前按抽签顺序将飞行器摆放至审核区，审核合格后进入准备区；进准备区
  后须关闭所有电子设备（允许计算机睡眠/休眠）。
- 每轮：**进场准备时间 1 分钟** + **比赛时间 5 分钟**。
- "进场准备开始"口令后：机组进入准备区，开启飞行器电源，向裁判演示
  人工安全开关可以正常工作，完成飞行前检查，举手示意"准备完毕"。
- "比赛时间开始"口令后：机组将飞行器放至起降点，安装标准载荷，**先
  按下计时器启动开关，再开启飞行器**（开启状态以螺旋桨开始旋转为准）；
  比赛时间开始后，**除紧急停止外不允许任何形式的人工操纵**。
- 飞行器自动起飞后，自动沿预设航线飞至投放区上方，自动将 2 个标准
  载荷投放至 3 个圆筒中的**任意 2 个**；两个载荷都需投至投放区内，且
  至少一个投至有效区（A 或 B 区），才能继续执行后续任务，否则比赛
  终止。
- 投放完毕后，飞行器继续飞往侦察区执行侦察，机组根据飞行器传回的
  信息填写成绩记录单；填写完毕即停止计时，之后不允许再改；着陆和
  填表无顺序要求。
- 飞行器必须**完全静止后**，机组人员才能回收。
- **比赛期间（检录开始至本轮结束）**，组委会统一管理所有机组的飞行器、
  地面站、图传等设备，不接受任何理由的维修与调整申请；机组进入准备区
  后、"进场准备开始"口令发出之前，可以对机械结构进行维修调试，经裁判
  允许可以开启除图传以外设备的电源。**未经裁判允许打开图传电源**属于
  取消资格的情形（见第 7 节）。

## 6. 成绩评定

单轮成绩 = 起飞分 + 空投分 + 侦察分 + 着陆分 + 时间分。**比赛成绩取两轮
中较高一轮**（不是两轮相加）。

| 分项 | 计分规则 |
|---|---|
| 起飞分 | 成功 **50** / 失败 **0**（携带 2 个标准载荷飞越起飞线即为起飞成功） |
| 空投分 | 命中 1 号筒/A区 **+500**，2 号筒/A区 **+300**，3 号筒/A区 **+100**，投至筒外/B区 **+50**，投至无效区或区外 **0**（以标准载荷第一落点判定；两个载荷投中同一 A 区算一次有效，投中同一 B 区算两次有效；若有载荷投至投放区外，或两个都投至无效区，比赛终止） |
| 侦察分 | 每个圆筒的危化品标识：填对 **+100**，填错 **−100**，空白 **0** |
| 着陆分 | 成功 **50** / 失败 **0**（比赛时间内、飞行器无损，落在起降点内，螺旋桨完全停止旋转） |
| 时间分 | `200 × (300 − T) / 300`，T = 计时秒数（精确到 1 秒去尾）；**只有完赛（起飞+空投分非0+侦察至少一项正确+着陆成功，且已填成绩记录单）才能得时间分**，否则为 0 |

比赛成绩 = `max(第一轮单轮成绩, 第二轮单轮成绩)`；成绩相同则以另一轮
成绩排序，成绩高者列前；仍相同则并列。

## 7. 判罚要点（详见规则原文第 36–41 页 / 物理页 38–43）

- **终止比赛，已得成绩有效**：飞行中触地；未完成投放即携带标准载荷
  进入侦察区；有标准载荷投至投放区外，或两个都投至无效区；停表时未
  填写成绩记录单；比赛时间内未着陆；停表时螺旋桨未停止旋转；**开启
  飞行器后有任何形式的人工操纵**。
- **该轮成绩为零分**：螺旋桨旋转前未按下计时器启动开关；起飞未成功或
  未飞越起飞线即着陆；起飞未挂载标准载荷；比赛时间终止时飞行器未着陆
  且机组未停表；起飞/飞行/着陆时发生零件脱落、解体或坠毁；飞行器两次
  飞入安全区（第一次警告）；裁判发现飞行器有明显安全隐患。
- **取消比赛资格**：赛前飞行器审核不合格，且更换一次后仍未通过审核；
  起飞前使用任何技术手段提前确定投放区/侦察区圆筒位置；飞行中触碰
  任何人员；未经裁判允许打开图传电源；发现作弊行为。
