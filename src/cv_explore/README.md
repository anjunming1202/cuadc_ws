# cv_explore —— 圆筒检测算法探索沙盒

**非 cuadc 前缀、非 colcon 包**的探索区(和 `src/camtune`、`src/cylinder_dataset`
一样游离在任务链路外)。这里是**高自由度试算法**的地方,不是生产模块。跑通、
提炼出有效方法后再决定怎么整理、往哪并——**当前不预先绑定提炼去向**。

## 沙盒规则

- **一个方法 = 一个文件夹**,彼此**平级、无序号**(`color_shape/`、`radial_symmetry/` …)。
  路径互不相交 → 并行开发、合回探索分支**零冲突**。
- **文件夹内完全自由**:自己写脚本、自己的中间产物可视化、自己的参数,不用细分模块。
- **`out/` 一律不进库**(见 `.gitignore`):中间图、拼接大图、`detections.csv`、重建图都放各方法的 `out/`。
- **`_shared/` 是可选便利、冻结只读**:公共 I/O 和反投影几何。要改就 **copy 进自己文件夹再改**,
  别就地改——这样它永远不会变成并行 worktree 的冲突点。

## 分支 / worktree 模型

- 探索主分支:**`feature/cv-explore-20260920`**(本轮战役;多轮调试=分支上多次提交/多个文件夹)。
- 并行时每个方法一个 **实验分支**,从主分支切出、合回主分支:命名 `cvx/<method>`
  (不能用 `feature/cv-explore-20260920/<method>`——会和主分支同名 ref 冲突)。
- worktree 放在**仓库工作区的同级目录** `../cuadc_ws_worktrees/<name>/`,各 worktree 并列。
- 单线开发(骨架 + 第一个方法)直接在主分支的主工作区做,worktree 只在真正并行时才用。

## 方法清单(平级)

| 方法文件夹 | 思路 | 角色 | 状态 |
|---|---|---|---|
| `color_shape/` | HSV 彩色分割(蓝垫+白筒)+ "白盘套蓝盘"同心先验 → 拟合圆 | 主攻(颜色比边缘抗糊) | 未开工 |
| `radial_symmetry/` | 灰度/mask 上做径向对称/距离变换找同心中心 | 颜色鲁棒,给 color_shape 精修或备份 | 计划 |

YOLO 等学习式方法**本轮不做**——没标注、且需要质量更好的数据集,等相机调参改善后再议。

## 用哪套数据

主用 `src/cylinder_dataset/data/cylinder_20260916_01_20260916_180235`(200 帧,
`_shared/dataset.py` 的默认组)。另一组 `cylinder_bench_1p3m_*` **带几何真值**
(筒正前 1.3m)可用来**校验反投影数学**,但曝光偏暗、图像质量待查。

## 这套数据的实况(设计依据,来自实际翻阅)

- **目标长相**:白色圆筒直立(俯视=白色顶圈)立在**蓝色大圆垫**中央(垫边一圈金属气眼),草地背景。
  俯视签名 = **白盘套在蓝盘里的同心结构**。
- **干扰物**:黑红条纹泡沫滚轴(几乎每帧都在,红强但面积小)、笔记本、鞋、手臂、水瓶。
- **整套 200 帧都很糊**(失焦 + 手持运动模糊)——算法必须**扛糊**(颜色比边缘可靠)。
- **可用目标帧约 79–200**(蓝垫在画面里),最佳大视图 96–148;前 1–78 基本只有滚轴+草。
- **无检测标注、无相机标定**(`run_meta` 里外参/内参/靶标真值都没填)→ 走无监督/经典法。
- 位姿齐全:每帧 `roll/pitch/yaw` + NED xyz + lat/lon + rel_alt(dgps/32 星)。操作者基本
  站在 ~6×2m 一点、~1m 高、姿态狂摆——三个筒挤在这一小片区域被分别框到。

## 无标注怎么看效果:位姿 + 检测 → 反投影聚类

每帧检测中心 → 过该像素的世界射线(用位姿)。两种读法:
- **射线交汇密度(免高度,先用这个)**:画各帧射线,看交汇浓处 = 目标位置;不依赖高度,最配这套手持数据。
- **地面/筒顶反投影散点(需高度,后用)**:射线交平面得地面点,累积成散点看聚成几簇。

同一目标从多姿态反投影应聚成**紧簇**,不同目标成不同簇——**簇数+紧致度 = 无标注的质量读数**,
不关心原点在哪。反投影几何借自 `cuadc_perception/cv_pipeline.py`(见 `_shared/geometry.py`),
但那套只在 sim 试过、且用灰度 Otsu(不吃颜色,没转过来);本套手持内外参没填,反投影尺度粗糙,
这里**定性**看,真正发力在真实飞行。
