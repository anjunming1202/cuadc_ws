# _shared —— 冻结只读的公共件

各方法**可选**共用的公共件,只有两样,都是稳定 I/O / 几何,不含任何检测算法:

- `dataset.py` —— 读某组 dataset 的帧 + 位姿(纯 I/O)。
- `geometry.py` —— 像素↔世界的反投影/射线几何(借自 `cuadc_perception/cv_pipeline.py`,
  改成吃本数据集的欧拉角姿态)。**约定未在本手持数据上验证过**,详见文件内注释。

## 规则:冻结、只读、copy-to-diverge

- 把这里当**只读**用:方法文件夹 `import` 它没问题。
- **需要改?复制到你自己的方法文件夹再改**,不要就地改。
- 这样并行的多个 worktree 永远不会在这里撞车。真有某个公共件被普遍验证好了、值得升级,
  单独提出来在主分支上改一次,而不是各 session 各改各的。
