# DroneLink：天空端 / 地面端分工与树莓派安装指南

本文面向要把图传（及后续遥测）跑通的同学。仓库路径：`src/dronelink/`。

---

## 1. 两端各要完成什么（简述）

### 天空端（树莓派，机载）

| 事项 | 状态 |
|---|---|
| 硬件：Pi 5 + IMX519 相机 + USB-AC56（AP） | 必需 |
| 开 5 GHz AP（SSID `DroneLink`，本机 `192.168.50.1`） | 本仓库已有脚本/配置 |
| 采集相机 → H.264 → RTP/UDP 发到地面 `192.168.50.2:5600` | 本仓库已有 systemd |
| 维护网线 `10.10.10.1`（SSH，可选） | 本仓库有示例 |
| 把飞控高度/姿态等打成 JSON，UDP 发到 `192.168.50.2` 的 `:5701` 与 `:5601`（有线也可同时发 `10.10.10.2`） | 脚本已提供；未连飞控时也会先发 `link=connecting`，便于区分「无 UDP」与「等飞控」 |

天空端职责一句话：**建网 + 推视频（+ 以后推遥测）**，不在这条链路上接收地面控机指令。

### 地面端（Windows）

| 事项 | 状态 |
|---|---|
| USB-AC56 连 `DroneLink`，静态 IP `192.168.50.2` | 手工配置 |
| 安装 Python 3、FFmpeg | 一次性 |
| 跑 `windows/start_dronelink_ground.bat`，浏览器打开 `http://127.0.0.1:8765/` | 本仓库已有（连网 + viewer；勿开两个 viewer） |
| 收视频 `:5600`，收遥测 JSON `:5701`/`:5601`，同页 HUD 显示 | 本仓库已有（可用 `send_fake_telemetry.py` 本机测 HUD） |

地面端职责一句话：**收流 + localhost 同屏显示**（只监看，不回控）。

### 端口约定

| 内容 | 目标 |
|---|---|
| 图传 RTP/H.264 | `192.168.50.2:5600`（viewer 代理后再给本机 FFmpeg） |
| 共享 UDP | `192.168.50.2:5601`（遗留遥测 JSON；与 RTCP 由 viewer 分流） |
| 遥测 JSON/UDP | `192.168.50.2:5701`（可选同时 `10.10.10.2`；Pi 同时发 `5701,5601`） |

## 2. 树莓派端：需要准备什么 / 如何安装

下面按「新刷或新配一台 Pi」的顺序写。路径均相对仓库里的 `src/dronelink/`。

### 2.1 硬件清单

- Raspberry Pi 5
- Arducam / Sony IMX519 相机（CSI）
- ASUS USB-AC56（RTL8812AU）一块，作机载 AP
- （推荐）网线：Pi ↔ Windows，用于 SSH / 拷文件（`10.10.10.0/24`）
- 足够供电的电源

### 2.2 系统与基础软件

建议使用较新的 **Raspberry Pi OS（64-bit）**。首次开机完成用户创建后：

```bash
sudo apt update
sudo apt install -y \
  hostapd \
  iw \
  wireless-tools \
  ethtool \
  gstreamer1.0-tools \
  gstreamer1.0-plugins-base \
  gstreamer1.0-plugins-good \
  gstreamer1.0-plugins-bad \
  gstreamer1.0-libav \
  libcamera-apps \
  git
```

说明：

- **hostapd**：把 USB 网卡开成 AP  
- **GStreamer + libcamera**：图传编码与推流  
- 若 `gst-launch-1.0` 找不到 `libcamerasrc` / `x264enc`，再按报错补装对应插件（例如 `gstreamer1.0-libcamera`、`gstreamer1.0-plugins-ugly` 等，以你系统源为准）

关闭系统自带的 Wi‑Fi 管理对 USB 网卡的抢占（按你实际发行版调整；冲突时 hostapd 起不来）：

```bash
# 示例：若使用 NetworkManager，可对专用网卡设 unmanaged，或禁用 wpa_supplicant 占用该口
# 具体以现场发行版文档为准，目标是：USB-AC56 只给 hostapd 用
```

### 2.3 内核驱动（仓库不附带二进制，需本机编译）

以下与内核版本绑定，**不能**从本仓库直接拷 `.ko` 通用安装：

1. **RTL8812AU / 88XXau**  
   - USB-AC56 插上后应出现无线网卡（`ip link` 能看到，名称可能是 `wlx…`）  
   - 按芯片社区/厂商说明编译安装驱动  

2. **AK7375 VCM（对焦）**  
   - 若要用对焦相关能力，按 Arducam/驱动说明编译安装  
   - 当前生产图传配置**不依赖**连续自动对焦；没装好对焦模块一般仍可推流  

驱动装好后确认：

```bash
ip link
# 记下 USB-AC56 的接口名，例如 wlxa85e4565195f
libcamera-hello --list-cameras
# 应能看到 IMX519
```

### 2.4 把本仓库配置拷到系统路径

在能访问仓库的前提下（git clone 或 U 盘拷贝），假设仓库在 `~/cuadc_ws`：

```bash
cd ~/cuadc_ws/src/dronelink

sudo mkdir -p /etc/dronelink
sudo mkdir -p /etc/systemd/system/dronelink-video.service.d

sudo cp raspberrypi/scripts/dronelink-network.sh /usr/local/sbin/dronelink-network.sh
sudo cp raspberrypi/hostapd/hostapd.conf /etc/dronelink/hostapd.conf
sudo cp raspberrypi/systemd/dronelink-network.service /etc/systemd/system/
sudo cp raspberrypi/systemd/dronelink-video.service /etc/systemd/system/
sudo cp raspberrypi/systemd/dronelink-video.override.conf \
  /etc/systemd/system/dronelink-video.service.d/override.conf
sudo cp raspberrypi/systemd/eth0-100m.service /etc/systemd/system/

sudo chmod +x /usr/local/sbin/dronelink-network.sh
```

### 2.5 必须按本机改的三处

**（1）无线网卡接口名**

编辑：

- `/usr/local/sbin/dronelink-network.sh` 里的 `IFACE=...`
- `/etc/dronelink/hostapd.conf` 里的 `interface=...`

改成你 `ip link` 看到的 USB-AC56 名（仓库默认是某台机器上的 `wlxa85e4565195f`，换机必改）。

**（2）图传服务运行用户**

`/etc/systemd/system/dronelink-video.service` 中有：

```ini
User=wly
```

改成你 Pi 上的实际用户名，并保证该用户能访问相机（通常需在 `video` 等组内）。

**（3）维护网线静态 IP（推荐）**

参考 `raspberrypi/netplan-example.yaml`，给 `eth0` 配：

- Pi：`10.10.10.1/24`  
- Windows 对端：`10.10.10.2/24`  

应用 netplan（文件名按你系统习惯）：

```bash
sudo nano /etc/netplan/99-dronelink-eth.yaml   # 写入示例内容
sudo netplan apply
```

并启用强制 100M 全双工（避免个别 1G 链路掉载波）：

```bash
sudo systemctl enable eth0-100m.service
sudo systemctl start eth0-100m.service
```

### 2.6 启用图传相关服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable dronelink-network.service
sudo systemctl enable dronelink-video.service
sudo systemctl start dronelink-network.service
sudo systemctl start dronelink-video.service
```

检查：

```bash
systemctl status dronelink-network.service
systemctl status dronelink-video.service
ip addr show   # 图传口应有 192.168.50.1/24
journalctl -u dronelink-video.service -e
```

当前**实际生效**的推流参数在 `override.conf`（以拷到系统的为准）：

- 1920×1080@30，H.264，约 6000 kbps，低延迟 x264  
- 发往 `192.168.50.2:5600`

（仓库里 `dronelink-video.service` 正文可能仍是旧分辨率示例；**以 override 为准**。）

### 2.7 网络侧自检（Pi 上）

```bash
# AP 起来后，地面应能搜到 SSID DroneLink，密码见 hostapd.conf（默认 12345678）
ping -c 3 192.168.50.2   # 地面连上并设好静态 IP 之后
```

图传不经过 ROS；只要上述服务正常，地面跑 localhost viewer 即可收画面。

### 2.8 飞控遥测回传（当前：无 ROS，pymavlink）

仓库已提供：

- `raspberrypi/scripts/dronelink-telemetry.py`
- `raspberrypi/systemd/dronelink-telemetry.service`

安装到 Pi（在已 clone 的仓库目录下）：

```bash
sudo apt install -y python3-venv python3-full
python3 -m venv ~/dronelink-venv
~/dronelink-venv/bin/pip install -U pip
~/dronelink-venv/bin/pip install pymavlink

sudo cp raspberrypi/scripts/dronelink-telemetry.py /usr/local/sbin/dronelink-telemetry.py
sudo chmod +x /usr/local/sbin/dronelink-telemetry.py
sudo cp raspberrypi/systemd/dronelink-telemetry.service /etc/systemd/system/
# 若用户名不是 wly：sudo nano 改 User= 和 ExecStart 里的 /home/xxx/dronelink-venv
sudo usermod -aG dialout wly   # 改成你的用户名；改完需重新登录
sudo systemctl daemon-reload
```

**先手动验证，再 enable 服务**（见联调步骤）。串口同时只能给一个进程用：开着本服务时不要再跑以后的 ROS `cuadc_interface`。

日后迁 ROS：停掉本服务，改由订 `/cuadc_interface/telemetry/*` 发同一套 JSON；地面 HUD 协议不变。

从 **Windows** 一键同步遥测脚本/服务到 Pi（会提示 SSH 密码；**不要在 Pi 的 bash 里跑** `.ps1`）：

```powershell
cd e:\cuadc_ws\src\dronelink\windows
.\deploy_pi_telemetry.ps1
```

服务默认向 `192.168.50.2` 与 `10.10.10.2` 同时发 `:5701` 与 `:5601`；
不等飞控心跳也会先发 UDP（`link=connecting`）。有线未接时 Ethernet 目标会静默失败。

**地面开机连网慢（WLAN 2 很久才发现 DroneLink）：** 本机做一次
`windows\tune_wlan2_dronelink.ps1`，日常用 `windows\start_dronelink_ground.bat`。

## 3. 地面端最小步骤（对照用）

1. USB 网卡连 `DroneLink`，IP `192.168.50.2/24`  
2. 安装 Python、FFmpeg  
3. （建议一次）`tune_wlan2_dronelink.ps1`  
4. `cd …\src\dronelink\windows` → `start_dronelink_ground.bat`  
5. 浏览器打开 `http://127.0.0.1:8765/`  

**开机：** Pi 上 `dronelink-network` / `video` / `telemetry` 若已 `enable`，上电自启。
地面仍需每次跑 `start_dronelink_ground.bat`。有画面但 HUD「等待飞控」= 飞控串口无心跳；
「无数据」= Pi 没发 UDP。

扫不到 `DroneLink` 且网线通：`windows\fix_pi_ap_over_ethernet.ps1`。

更细说明见主文档 `src/dronelink/README.md`。
